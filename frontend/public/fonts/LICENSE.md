# Bundled fonts

Both families are licensed under the SIL Open Font License 1.1, which permits
bundling and web embedding. Files are the variable `latin` / `latin-ext`
subsets served by the Google Fonts CDN.

- **Archivo** (`archivo-var-*.woff2`) — Omnibus-Type.
  Axes: `wght` 100–900, `wdth` 62–125.
  <https://github.com/Omnibus-Type/Archivo> · OFL-1.1

- **Inter** (`inter-var-*.woff2`) — Rasmus Andersson.
  Axes: `wght` 100–900, `opsz` 14–32.
  <https://github.com/rsms/inter> · OFL-1.1

Used as: Archivo for display (page titles, wordmark, race clock, finish
times), Inter for everything else. See the `@font-face` block at the top of
`src/styles.css`.
